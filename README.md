# Nike Shoes Sales Dashboard 👟📊

## 📌 Project Overview
This project analyzes Nike’s sales performance using a dataset of product sales, regions, and categories.  
The main goal was to identify best-selling products, underperforming categories, and regional sales distribution.

## 🎯 Objectives
- Analyze overall sales performance.
- Identify top-performing products and regions.
- Understand sales trends and areas for improvement.
- Create a clean, engaging dashboard that reflects Nike’s brand identity.

## 🧰 Tools Used
- Power BI  
- Excel  
- DAX  
- Data Visualization & Dashboard Design

## 🎨 Dashboard Design
We focused on matching the **Nike website theme**, using similar **color palettes, typography, and layout** to make the visuals intuitive and engaging.

## 📈 Key Insights
- Highlighted top 10 best-selling product categories.  
- Identified regions with the highest and lowest sales.  
- Detected underperforming products that could affect profitability.
